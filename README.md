# 🎵 Android Reclip **Android Reclip** is a modern, lightweight Android application built with **Jetpack Compose** and **Kotlin**. It continuously records audio in a rolling background buffer—allowing you to capture and save audio clips from the recent past on demand. Never miss a moment again! --- ## ✨ Features * **Rolling Audio Buffer:** Continuously captures audio in a background circular buffer (defaulting to the last 2 minutes). * **Instant Clipping:** Tap the primary **CLIP** button to pull the audio buffer directly into an editor. * **Modern UI:** Built using Material 3 guidelines, supporting clean card layouts, dynamic timestamps, and smooth animations. * **Interactive Waveform Scrubber:** Tap or drag your finger smoothly along the audio timeline to seek and preview audio clips in real time. * **Flexible Storage:** Choose to save audio clips internally or pick a custom folder using the Android Storage Access Framework. * **Easy Sharing:** Export and share saved `.wav` clips directly to other applications via the native Android share sheet. * **Theme Customization:** Full support for Light, Dark, and System Default themes. --- ## 🛠️ Built With * **Language:** [Kotlin](https://kotlinlang.org/) * **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material 3) * **Architecture:** Foreground Services, Service Binding, Coroutines * **Audio Engine:** `AudioRecord` (PCM 16-bit recording) & `MediaPlayer` (playback) --- ##
